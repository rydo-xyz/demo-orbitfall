# Orbitfall — DEMO ONLY

**Fictional single-game launch / wishlist landing** built for the **Kerbstone Studio** portfolio to demonstrate a premium Spark-tier game site.

- Not a real game or Steam listing
- Wishlist / store buttons are stubs (`#` / `javascript:void(0)`) labelled **DEMO**
- Trailer is a CSS/SVG mock player — no YouTube, no real footage
- Do **not** present this as a live client or shipping product

## Sections

Cinematic hero · trailer mock · features (6) · platform chips · press kit stub · Netlify Forms wishlist · FAQ · footer DEMO badge · `thanks.html`

## Stack

Static HTML / CSS / JS. Google Fonts (**Syne** + **DM Sans**). Netlify Forms (`orbitfall-wishlist`) with honeypot. Parallax-ish CSS layers + scroll reveal.

## Deploy

Publish directory is `.` (this folder). Site name: `kerbstone-demo-orbitfall`. No custom domain. `X-Robots-Tag: noindex` via `netlify.toml`.
